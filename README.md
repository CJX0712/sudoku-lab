# Sudoku Lab · 数独实验室

零依赖 · 单文件 HTML 数独生成与求解器，**唯一解保证**。浏览器打开即玩，Node 无头自检全绿。

## 运行

双击 `index.html` 即可，无需服务器、无需构建、无任何外部依赖。
`sudoku.html` 为引擎 + 自检同源版本（页面入口与 `node_selftest.js` 共用同一套核心函数）。

## 功能

- **生成**：入门 / 进阶 / 困难三档（挖洞 38 / 48 / 54），每挖一格都用解计数器验证全局唯一解
- **求解**：MRV（最少候选优先）回溯求解，实时统计回溯步数
- **提示**：单格提示，其余不变
- **校验**：行 / 列 / 宫 27 组「1–9 恰好一次」终盘有效性检查

## 可验证的不变量

| 不变量 | 验证方式 |
| --- | --- |
| 谜题唯一解 | 挖洞前 `solveCount(puzzle, 2).count === 1`（解计数器上限剪枝） |
| 终盘有效 | 27 组（9 行 + 9 列 + 9 宫）各恰好包含 1–9 |
| 生成器正确性 | 随机回溯填充后再做终盘有效性检查 |

## 无头自检

```bash
node node_selftest.js
# selfTest(50): pass=50 fail=null 150ms
# ALL GREEN ✅
```

50 张随机谜题：全部唯一解、终盘全部有效。
